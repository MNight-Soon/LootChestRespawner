# Loot Chest Respawner

A Forge mod for Minecraft 1.20.1 that makes ordinary chests respawn loot after a configurable cooldown.

## Features
- Normal chest loot respawns after a set number of in-game days
- Randomized loot pulled from Minecraft loot tables
- Configurable respawn timing
- Optional compatibility hook for Lootr when present

## Planned next steps
